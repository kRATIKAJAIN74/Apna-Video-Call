# 🎯 Responsive Design Quick Reference Card\n\n## Breakpoints\n```\n📱 Mobile:  320px - 480px\n📱 Tablet:  481px - 768px  \n💻 Desktop: 769px - 1199px\n🖥️  Large:   1200px+\n```\n\n## Essential CSS Patterns\n\n### Fluid Sizing\n```css\nfont-size: clamp(MIN, PREFERRED, MAX);\npadding: clamp(0.5rem, 2vw, 1.5rem);\nwidth: clamp(200px, 80vw, 800px);\n```\n\n### Mobile-First Flexbox\n```css\n.container {\n  display: flex;\n  flex-direction: column;  /* Stack on mobile */\n  gap: clamp(1rem, 3vw, 2rem);\n}\n\n@media (min-width: 769px) {\n  .container {\n    flex-direction: row;   /* Side-by-side on desktop */\n  }\n}\n```\n\n### Hide/Show Elements\n```css\n/* Hide on mobile */\n@media (max-width: 480px) {\n  .desktop-only { display: none; }\n}\n\n/* Show on desktop */\n@media (min-width: 769px) {\n  .sidebar { display: block; }\n}\n```\n\n## Media Query Breakpoints\n\n```css\n/* Tablets and up */\n@media (min-width: 481px) { }\n\n/* Desktops and up */\n@media (min-width: 769px) { }\n\n/* Large desktops */\n@media (min-width: 1200px) { }\n\n/* Landscape orientation */\n@media (orientation: landscape) { }\n\n/* Touch devices */\n@media (hover: none) { }\n```\n\n## Responsive Components\n\n### Responsive Button\n```css\nbutton {\n  min-height: 44px;  /* Touch-friendly */\n  min-width: 44px;\n  padding: clamp(0.6rem, 2vw, 1rem) clamp(1rem, 3vw, 1.5rem);\n  font-size: clamp(0.85rem, 2vw, 1rem);\n}\n\n@media (max-width: 480px) {\n  button { width: 100%; }  /* Full width on mobile */\n}\n```\n\n### Responsive Grid\n```css\n.grid {\n  display: grid;\n  grid-template-columns: 1fr;  /* 1 column on mobile */\n  gap: clamp(1rem, 3vw, 2rem);\n}\n\n@media (min-width: 481px) {\n  .grid { grid-template-columns: repeat(2, 1fr); }  /* 2 on tablet */\n}\n\n@media (min-width: 1024px) {\n  .grid { grid-template-columns: repeat(3, 1fr); }  /* 3 on desktop */\n}\n```\n\n### Responsive Image\n```css\nimg {\n  width: 100%;\n  height: auto;\n  max-width: 100%;\n  object-fit: cover;  /* Prevent distortion */\n}\n```\n\n## Common Issues & Fixes\n\n| Issue | Fix |\n|-------|-----|\n| Text too small on mobile | Use `clamp()` or media query |\n| Buttons hard to tap | Min 44px × 44px |\n| Layout breaks at edge | Use `max-width: 100%` |\n| Horizontal scrolling | Check padding, use %/clamp |\n| Images distorted | Use `object-fit: cover` |\n| Text unreadable | Adjust font size, line-height |\n\n## CSS Units Cheat Sheet\n\n| Unit | Use For | Example |\n|------|---------|----------|\n| `px` | Fixed sizes, borders | `border: 1px solid;` |\n| `rem` | Typography | `font-size: 1.2rem;` |\n| `em` | Relative to parent | `margin: 1.5em;` |\n| `%` | Relative to parent | `width: 50%;` |\n| `vw` | Viewport width | `width: 80vw;` |\n| `clamp()` | Fluid sizing | `font-size: clamp(1rem, 3vw, 2rem);` |\n\n## Testing Devices\n\n### Mobile\n- iPhone SE (375px)\n- iPhone 12-15 (390-430px)\n- Galaxy A series (412px)\n\n### Tablet\n- iPad (768px)\n-
